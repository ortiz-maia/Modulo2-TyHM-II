# Modulo2-TyHM-II

# Taller de Fotografía

Este informe reúne los resultados del Módulo 2 del Taller de Fotografía, donde exploramos cómo usar la cámara como una herramienta clave para registrar y analizar evidencias en la ingeniería. A lo largo del trabajo combinamos dos enfoques: por un lado, analizamos una barra de metal rota para estudiar qué causó la falla y cómo documentarla correctamente con fotos; por otro, evaluamos los aspectos técnicos de la luz, el enfoque y la composición en una imagen tomada en el mismo ámbito universitario. La idea principal es mostrar cómo una buena fotografía puede servir como prueba clara y confiable.
